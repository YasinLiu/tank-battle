# Tank Battle - 坦克大战

A classic tank battle game built with HTML5 Canvas, CSS, and vanilla JavaScript.

## Features

- Player tank with WASD/Arrow key controls
- AI-controlled enemy tanks with pathfinding
- Destructible brick walls and indestructible steel walls
- Grass cover and water obstacles
- Multi-level progression with increasing difficulty
- Score tracking and lives system
- Explosion effects and animations

## How to Play

1. Open `index.html` in your browser
2. Click **START GAME**
3. Use **WASD** or **Arrow Keys** to move
4. Press **Space** to shoot
5. Destroy all enemies to advance to the next level
6. Protect your base (the golden star) at all costs!

## Tech Stack

- HTML5 Canvas for rendering
- Vanilla JavaScript (no frameworks)
- CSS3 for UI styling
